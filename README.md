# 🏓 핑퐁 게임 (Pong)

브라우저에서 바로 돌아가는 클래식 핑퐁 게임입니다.
설치도, 빌드도, 서버도 필요 없습니다. **HTML 파일 하나가 전부입니다.**

---

## 실행 방법

`pong.html` 파일을 더블클릭하면 기본 브라우저에서 바로 열립니다.

```
git clone https://github.com/kimdaniel0906-star/ajck.git
cd ajck
start pong.html        # Windows
open  pong.html        # macOS
```

외부 라이브러리를 전혀 쓰지 않으므로 인터넷 연결 없이도 동작합니다.

---

## 조작

| 입력 | 동작 |
|---|---|
| 마우스 이동 / 터치 | 왼쪽 패들이 커서를 부드럽게 따라감 |
| `↑` `↓` 또는 `W` `S` | 패들 상하 이동 |
| `Space` | 일시정지 / 재개 |
| `R` | 현재 판 재시작 |
| `Enter` | 메뉴·결과 화면에서 시작 |

키를 누르는 동안에는 키 조작이 마우스 추종보다 우선합니다.

---

## 규칙

- 플레이어(왼쪽 🟢) vs 컴퓨터(오른쪽 🔴)
- **먼저 7점**을 얻으면 승리
- 득점하면 실점한 쪽으로 서브가 넘어갑니다
- **랠리가 이어질수록 공이 빨라집니다** (한 번 칠 때마다 1.045배, 상한 1150px/s)

---

## 난이도

| 난이도 | AI 반응 속도 | AI 실책률 | 초기 공 속도 |
|---|---|---|---|
| 쉬움 | 300 px/s | 약 48% | 330 px/s |
| 보통 | 420 px/s | 약 17% | 390 px/s |
| 어려움 | 560 px/s | 속도 한계로만 실책 | 450 px/s |
| 불가능 | 900 px/s | 사실상 없음 | 520 px/s |

AI는 벽 반사까지 계산해 공의 낙하 지점을 **정확히 예측**합니다.
난이도는 예측 능력이 아니라, 예측 지점에 더해지는 **무작위 오차의 크기**로 조절됩니다.
패들 반높이(48px)보다 오차가 클 때만 실제로 공을 놓치므로,
난이도가 올라갈수록 실책의 성격이 *우연*에서 *물리적 한계*로 바뀝니다.

---

## 구현 특징

- **각도를 만드는 반사** — 패들 중앙에 맞으면 빠르고 평평하게, 끝에 맞을수록 최대 56°까지 꺾입니다. 단순 반사가 아니라 각도로 공격할 수 있습니다.
- **터널링 방지** — 최고 속도에서 공은 한 프레임에 약 19px 움직이는데 패들 두께는 12px입니다. 매 프레임 이동을 6.4px 이하의 하위 스텝으로 쪼개, 어떤 속도에서도 공이 패들을 뚫고 지나가지 않습니다.
- **프레임 보정** — 탭을 전환했다 돌아와도 공이 순간이동하지 않도록 `dt`에 상한을 둡니다.
- **연출** — 공 잔상, 득점 파티클, 화면 흔들림, 발광 효과
- **사운드** — WebAudio로 실시간 합성 (오디오 파일 없음, 음소거 가능)
- **반응형** — 데스크톱·모바일 모두 지원, 캔버스 비율 유지 스케일링

## 검증

DOM과 Canvas를 스텁으로 대체해 Node.js에서 헤드리스로 구동하고,
렌더링 호출을 가로채 얻은 공 좌표를 그대로 포인터 입력으로 되먹여
**실수하지 않는 완벽한 플레이어**를 시뮬레이션했습니다. 난이도별 10분씩 실행:

| 난이도 | 완료 게임 | 최고 랠리 | 최장 정지 |
|---|---|---|---|
| 쉬움 | 6판 | 24 | 1.00s (서브 대기) |
| 보통 | 1판 | 108 | 1.00s |
| 어려움 | 0판 | — | 1.00s |
| 불가능 | 0판 | — | 1.00s |

- 공의 x 좌표가 46~854 범위를 벗어나지 않음 → **터널링 없음**
- 정지 구간이 서브 카운트다운 1.0초를 넘지 않음 → **공 끼임 없음**
- 10분 연속 구동 중 예외 없음

'어려움'과 '불가능'의 무득점은 의도된 결과입니다. 실수하지 않는 가상 플레이어 기준이며, 사람이 플레이하면 정상적으로 점수가 납니다.
